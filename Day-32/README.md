# Day 32 – Learning Roadmap & Responsive UI

On **Day 32** of the **50 Days Dev Web Development Challenge**, I focused on improving the **Synexus Official** platform by creating a structured **Learning Roadmap** section.

I designed the roadmap using **responsive cards** to organize different learning stages clearly. Each card includes a step number, title and description, making the learning journey easier to understand and follow.

I used **CSS Grid** and **media queries** to make the roadmap responsive across desktop, tablet and mobile screens. I also added hover effects, rounded cards, borders and shadows to create a clean and interactive user interface.

The roadmap follows the existing **lavender and purple Synexus theme** and supports both **light mode and dark mode** using CSS custom properties.

### What I Learned

* Creating structured roadmap sections using HTML.
* Using **CSS Grid** for responsive layouts.
* Using `auto-fit` and `minmax()` for flexible grids.
* Creating reusable card designs.
* Using CSS variables for consistent theming.
* Adding hover effects and smooth transitions.
* Using media queries for mobile responsiveness.
* Supporting light and dark themes.
* Improving UI consistency and user experience.

### Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* CSS Variables
* Media Queries
* Responsive Web Design
* CSS Transitions
* Dark Mode

### Outcome

Successfully created a **responsive Learning Roadmap** for the **Synexus Official** platform with structured cards, hover effects and responsive layouts.

The section matches the Synexus lavender and purple theme and works across different screen sizes while supporting both light and dark modes.

This day strengthened my understanding of **CSS Grid, responsive design, CSS variables, reusable components, dark mode and modern UI styling**.
