### Day 11 – Introduction to JavaScript & DOM Manipulation

On **Day 11** of the **50 Days Dev Web Development Challenge**, I began my JavaScript journey by connecting an external JavaScript file to my existing community platform and learning how to interact with the Document Object Model (DOM). This marked the transition from building a static website to creating an interactive user experience.

I linked the `script.js` file using the `defer` attribute, selected HTML elements with `document.querySelector()`, and stored them using `const` variables. I then implemented a `click` event listener on the Hero section button, allowing the webpage to dynamically update the Hero heading using the `.textContent` property. As part of the bonus challenge, I also created a custom CSS class and used `classList.toggle()` to dynamically change the heading's text color, demonstrating how JavaScript can manipulate CSS classes to create interactive UI effects.

### What I Learned

* Connecting an external JavaScript file using the `defer` attribute.
* Selecting HTML elements with `document.querySelector()`.
* Using `const` variables to reference DOM elements.
* Handling user interactions with `addEventListener()`.
* Updating webpage content dynamically using `.textContent`.
* Manipulating CSS classes with `classList.toggle()`.
* Understanding the fundamentals of DOM manipulation and interactive web development.

### Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* Document Object Model (DOM)

### Outcome

Successfully introduced JavaScript into the project by making the Hero section interactive. The webpage now responds to user actions by updating the Hero heading and dynamically toggling its styling, marking the first step toward building a fully interactive web application.
