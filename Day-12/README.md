### Day 12 – State Manipulation & Dynamic Menus (Mobile Navigation)

On **Day 12** of the **50 Days Dev Web Development Challenge**, I advanced my JavaScript skills by building a fully functional responsive mobile navigation system. This challenge focused on connecting HTML, CSS, and JavaScript to manage UI states dynamically and create an interactive hamburger menu experience.

I added a semantic menu toggle button inside the navigation section and used CSS media queries to control its visibility on mobile screens. Using JavaScript, I selected the menu button and navigation links with `document.querySelector()`, then implemented a `click` event listener to dynamically add and remove classes using `classList.toggle()`. This allowed the navigation menu to open and close based on user interaction.

As part of the bonus challenge, I enhanced the hamburger menu by replacing the default icon with custom CSS spans and added smooth CSS transform animations to morph the three bars into an "X" shape when the menu is active. This improved the user experience and introduced a more professional mobile navigation interaction.

### What I Learned

* Creating responsive mobile navigation menus using HTML, CSS, and JavaScript.
* Managing UI states dynamically with JavaScript.
* Selecting and manipulating DOM elements using `document.querySelector()`.
* Handling user interactions with `addEventListener()`.
* Using `classList.toggle()` to add and remove CSS classes.
* Creating hamburger menu animations using CSS transforms and transitions.
* Connecting JavaScript logic with CSS states to build interactive components.

### Technologies Used

### Outcome

Successfully built a responsive mobile navigation system with a functional hamburger menu.
